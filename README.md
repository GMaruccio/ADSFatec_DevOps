## 📘 Sobre o repositório

Este repositório funciona como um **caderno digital da disciplina de DevOps**. Seu objetivo é centralizar a documentação das aulas e manter organizados os materiais produzidos durante o semestre.

Mais do que armazenar arquivos, a proposta é registrar a evolução do aprendizado: desde os primeiros exercícios e pesquisas até a criação de aplicações, automação de processos, testes e documentação técnica.

### 🎯 Objetivos

- Organizar os relatórios e as atividades desenvolvidas durante a disciplina.
- Registrar os conceitos e ferramentas estudados em cada aula.
- Reunir os projetos práticos em um só lugar, com acesso aos respectivos repositórios.
- Documentar decisões, processos e conhecimentos adquiridos.
- Construir um histórico que possa ser consultado e ampliado futuramente.

## 🗂️ Atividades e projetos

Cada atividade possui sua própria pasta neste repositório. Quando existe um projeto prático em um repositório separado, o link externo está disponível na respectiva seção.

### Aula 02 — Rolador de Status RPG

**Tema:** desenvolvimento de uma aplicação relacionada ao universo de RPG.

Projeto desenvolvido em grupo para gerar e trabalhar com atributos/status de personagens de RPG.

- 📁 Pasta: [`Aula02_RoladorStatus`](./Aula02_RoladorStatus)
- 💻 Projeto: [RoladorDeStatusRPG](https://github.com/LuisGlauser/RoladorDeStatusRPG)

### Aula 03 — Landing Page

**Tema:** desenvolvimento de páginas web.

Atividade prática editando uma landing page de algum projeto do github e fazendo o deploy automatico com o vercel.

- 📁 Pasta: [`Aula03-LandingPage`](./Aula03-LandingPage)
- 💻 Projeto: [Aula03LandingPage](https://github.com/GMaruccio/Aula03LandingPage)

### Aula 04 — Ferramentas de CI/CD

**Tema:** pesquisa e compreensão de ferramentas utilizadas em integração e entrega contínua.

Atividade voltada ao estudo de ferramentas e soluções que apoiam a automação do ciclo de desenvolvimento e entrega de software.

- 📁 Pasta: [`Aula04_Ferramentas_CICD`](./Aula04_Ferramentas_CICD)
- 📄 Projeto/atividade: [Pesquisa e Resumo sobre Ferramentas de CI/CD](https://github.com/GMaruccio/Pesquisa-e-Resumo-sobre-Ferramentas-de-CI-CD)

### Aula 05 — Pipelines Automatizadas

**Tema:** automação de etapas do processo de desenvolvimento.

Atividade prática associada ao projeto Initiative Tracker, utilizada para explorar a organização e a automatização de processos.

- 📁 Pasta: [`Aula05_PipelinesAutomatizadas`](./Aula05_PipelinesAutomatizadas)
- 💻 Projeto: [INITIATIVE_TRACKER](https://github.com/GMaruccio/INITIATIVE_TRACKER)
- 🌍 Deploy: [https://initiative-tracker-gilt.vercel.app/](https://initiative-tracker-gilt.vercel.app/)
  
### Aula 07 — Testes Automatizados

**Tema:** testes unitários, testes de integração, testes de performance e Integração Contínua.

O projeto desenvolvido é um CRUD simplificado de fichas de personagens de D&D 5e. Ele foi utilizado como base para organizar e executar os três tipos de testes de maneira independente, além de configurar uma pipeline no GitHub Actions para executá-los a cada `push` na branch `main`.

- 📁 Pasta: [`Aula07_TestesAutomatizados`](./Aula07_TestesAutomatizados)
- 💻 Projeto: [RPG-Sheet_Manager](https://github.com/GMaruccio/RPG-Sheet_Manager)
- 🌍 Deploy: [rpg-sheet-maker.vercel.app](https://rpg-sheet-maker.vercel.app/)

### Aula 09 — Documentação do Projeto de Controle de Presença

**Tema:** documentação técnica e organização de projetos.

Atividade voltada à elaboração de documentação, contemplando objetivo, problema, escopo, requisitos funcionais e não funcionais, tecnologias, arquitetura, componentes e instruções para instalação, configuração, execução, testes e deploy.

- 📁 Pasta: [`Aula09_Documentacao`](./Aula09_Documentacao)
- 💻 Projeto: [Controle-De-Presenca](https://github.com/GMaruccio/Controle-De-Presenca)

## 📁 Organização do repositório

A estrutura principal está organizada por aula, facilitando a localização dos relatórios e materiais correspondentes.

```text
ADSFatec_DevOps/
├── Aula02_RoladorStatus/
├── Aula03-LandingPage/
├── Aula04_Ferramentas_CICD/
├── Aula05_PipelinesAutomatizadas/
├── Aula07_TestesAutomatizados/
├── Aula09_Documentacao/
└── README.md
```

> A atividade da Aula 08 está vinculada a um repositório independente. Caso você também adicione seus arquivos e relatório a este caderno, inclua aqui a pasta correspondente.

## 🔎 Como explorar

1. Escolha a aula desejada na seção [Atividades e projetos](#-atividades-e-projetos).
2. Acesse a pasta correspondente para consultar o relatório e os materiais.
3. Quando disponível, utilize o link do projeto para visitar seu repositório independente.
4. Consulte os READMEs de cada projeto para encontrar instruções específicas de instalação e execução.

Este repositório é principalmente documental. Os procedimentos para executar cada aplicação estão descritos nos respectivos projetos.
