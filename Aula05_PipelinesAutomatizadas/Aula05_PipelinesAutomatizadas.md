#  Aula de DevOps — Automação de Pipeline com GitHub Actions

##  Conteúdo da aula

Nesta aula, foi proposta uma atividade prática para aplicar conceitos de automação e CI/CD utilizando o **GitHub Actions** e ferramentas disponíveis no **GitHub Marketplace**.

A atividade consistiu em escolher **três Actions**, integrar cada uma delas a uma etapa adequada de uma pipeline automatizada e configurar um workflow no GitHub Actions para executar o processo.

##  Objetivo da atividade

Desenvolver um projeto que utilizasse três Actions do GitHub Marketplace em uma pipeline, demonstrando como essas ferramentas podem automatizar tarefas do fluxo de desenvolvimento.

O professor solicitou que fossem realizadas as seguintes etapas:

1. Escolher três Actions disponíveis no GitHub Marketplace.
2. Desenvolver ou selecionar um projeto para utilizar na atividade.
3. Configurar um workflow no GitHub Actions.
4. Integrar cada Action à etapa apropriada da pipeline.
5. Executar a pipeline e verificar o funcionamento de cada etapa.
6. Documentar as Actions utilizadas, suas funções e sua contribuição para a automação.

##  Projeto desenvolvido — Initiative Tracker

Para realizar a atividade, foi desenvolvido um projeto simples voltado à organização da iniciativa de personagens durante combates em sessões de **Dungeons & Dragons (D&D)**.

O sistema permite registrar informações dos participantes do combate, como:

- **Nome:** identificação do personagem ou criatura.
- **Iniciativa:** valor utilizado para organizar a ordem de ação no combate.
- **CA (Classe de Armadura):** valor de defesa do personagem ou criatura.
- **HP (Pontos de Vida):** quantidade de vida do participante.

As informações são apresentadas em uma tabela, facilitando a consulta durante a sessão de RPG.

##  Pipeline de automação

A automação foi configurada por meio do **GitHub Actions**, utilizando um workflow para executar etapas automaticamente no projeto.

A proposta foi distribuir as três Actions escolhidas entre etapas adequadas do processo, permitindo automatizar tarefas que, de outra forma, poderiam precisar ser realizadas manualmente.

## Resultado e aprendizado

A atividade permitiu aplicar, em um projeto simples de RPG, conceitos de automação de processos e integração contínua utilizando o GitHub Actions.

O desenvolvimento do Initiative Tracker serviu como contexto para configurar e testar uma pipeline, enquanto as Actions do Marketplace foram utilizadas para automatizar etapas do fluxo de desenvolvimento.

A proposta demonstra como pipelines automatizadas podem reduzir tarefas manuais, padronizar verificações e facilitar a manutenção e evolução de um projeto.
